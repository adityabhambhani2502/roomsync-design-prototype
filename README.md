# RoomSync Design Prototype

A mobile app that connects college students with potential roommates based on shared interests and preferences, designed to ease the transition to campus life. Clean onboarding, preference-based matching, and a straightforward interface aimed at making the roommate search feel less overwhelming for incoming students.
